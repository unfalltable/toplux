# 本轮前台完善与验证

日期：2026-10-27。设备：Windows / Google Chrome。本轮在已有新版前台与公众助力实现上继续完善，没有重做身份、资金和后台业务。

## 实际改动

- 分离首页与品类的加载状态。切换品类时不显示旧品类的卡片或榜单；过期请求的成功、失败和结束状态均不会覆盖新请求。
- 品类读取失败时展示错误和“重新加载”，支持原地重试。
- 助力成功后同步刷新当前品类、跨品类总榜、品牌数据与当前浏览器订单。
- 品牌详情累计金额以服务端返回的各品类金额汇总，避免从品类榜进入时只展示单品类金额。
- 弹窗将背景设为 inert，Tab/Shift+Tab 限制在弹窗内；关闭后恢复原入口焦点，保留 Escape 关闭及减少动态效果偏好。
- 更新 npm run test:e2e 到当前页面流程；新增 tests/public-regression.ts。首页高奢视觉、三甲布局和原业务规则保持当前实现。
- README 更新为当前前台、品牌指标、独立后台与启动方式。
