# 公众助力与本轮视觉

用户本轮规则覆盖旧版：游客/普通用户无后台，任何人可为任意公开品牌向平台助力；不支持退款；品牌热度与关注直接展示在卡片，无独立商家数据页；前台无需登录。

身份与资金：匿名第一方Cookie保持关注与当前浏览器助力记录。订单归付款访客，收款方固定PLATFORM；品牌只作为榜单目标。创建订单及支付需CSRF和幂等保护。退款函数、HTTP入口及数据库新退款写入均拒绝；历史账本不重写。正式支付未接入，当前仍是明确标识的沙箱。

后台：独立 /admin 页面与构建入口。移除公开身份选择接口与旧管理角色会话权限；本机OS账号运行 scripts/open-admin.ps1 打开60秒一次性管理入口，不输出凭据。游客与普通用户访问 /admin 返回404，所有管理API仍验证角色。正式环境禁用本机入口，待正式身份接入。

卡片：热度=累计详情浏览次数，关注=匿名浏览器去重人数，官网/直播=平台跳转次数。无虚构热度。已发表图鉴品牌按中英文名建立稳定跨品类助力身份，维护映射后不随新付款改变。首页仍合并跨品类总榜。

视觉：曜石黑#111310、石墨#252720、香槟金#C5B58D、象牙白#F5F3ED、灰褐#8C8B80。字体为宋体标题/Georgia英文金额、微软雅黑正文。单行品牌导航 → 全幅低光工艺影像与居中标题 → 第二/冠军/第三独立品牌展示 → 其余品牌。卡片的关注和助力是明确按钮；去掉首页管理入口、角色切换及独立商家数据入口。手机冠军先呈现。

审视：上版偏普通导航加三张白卡，本版把视觉重点放在三甲的深色品牌展台，影像只保留一处，不增加推荐板块或虚构品牌数据。
