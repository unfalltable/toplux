# 品类品牌定位参考（初版）

整理日期：2026-10-27。覆盖 40 个品类、131 份资料，涉及 120 个独立品牌或明确命名的产品线。每个品类先提供 3—5 个代表，并非完整行业名录。

用户自行评估助力预算。本轮只建立图鉴资料与定位参考，不创建订单、到账、流水或虚构助力金额。首页累计助力仍只按真实的沙箱到账事件排序。

## 划分方式

仅在同品类内参考品牌历史积淀、代表作品、稀缺与定制、工艺及圈层认知划分层级。同层顺序为编辑阅读建议，不是公认结论；不以助力金额、广告费或单件最高价决定。

- 殿堂级：本品类的顶端代表，强调历史、代表作品、稀缺制作及圈层文化。
- 奢华级：奢华文化、经典作品与社交表达鲜明。
- 高端级：精品设计、制作或专业能力突出；不自动等同于传统奢侈品牌。
- 精品级／进阶级：为后续编辑补充设计特色与入门体验预留。
- 不适用：电脑等缺乏稳定奢侈阶序的领域，仅给出阅读顺序。

层级仅在同品类内阅读；高端专业参考单独标注。同层顺序属于编辑建议，没有公认先后，不是产品品质、售价、保值率或购买者身份的保证。付费金额不会修改定位。

## 内容维护与核对

初始资料在 `design/atlas-ranking.json`，既有七篇详细图鉴继续保留。后台品牌编辑可修改层级、同品类参考顺序、专业范围、理由和日期，经另一位审核员复核后公开。启动种子只增加缺失资料、为未改过的原始种子补上定位；不会覆盖编辑修订或恢复已下线内容。跨品类同名同英文名品牌共用助力身份。

本次核对了 120 个官网入口，其中 71 个在核对时正常返回品牌页面，49 个受访问限制、超时、页面异常或待复核；正常返回仅代表连通性与首页线索，不等于逐项事实审核。新资料对受限入口明确标注待人工复核。没有补造创办年份、价格、库存或品牌授权。

原始核对记录：`artifacts/catalog-source-check-v1.json`；区域入口修正：`artifacts/catalog-source-alternates-v1.json`。代表系列和品牌命名仍需编辑按官方当期目录持续核对，中文译名可能存在地区差异。

## 数据接口

`GET /categories` 在既有字段上增加真实公开资料数量 `brand_count` 与 `curation`（范围、方法、品类说明和日期）。品类图鉴优先显示真实资料；真实品牌搜索不再混入虚构演示。原演示数据与资金记录保留。

图鉴 `editorial.positioning` 为可选对象：`order`（1—9999 的整数）、`scope`（LUXURY／SPECIALIST）、`reason`、`asOf`（有效日期）；省略兼容旧资料，显式设 null 可移除参考。按层级分组、参考顺序和稳定名称排序，计算不读取推广金额。后台修改继续走原版本与第二人审核流程。
