# 奢品图鉴扩展方案

品牌卡及详情进入同一品牌的独立阅读页，使用品牌稳定ID深链接；按品牌匹配已发布图鉴，不通过名称模糊匹配其他品牌。无图鉴时展示该品牌专属的待完善页，平台可在新建资料时绑定上榜品牌。

视觉沿用深松绿#111310、香槟金#c5b58d、象牙白#f5f3ed、浅橄榄#e9ecdf、墨绿#34452a。宋体标题、微软雅黑正文、Georgia英文名。顶部以品牌英文名和中文名构成字标，中间左侧短目录、右侧单列阅读；代表产品用平铺条目，身份表达用简短解读，来源置底。手机为一列，阅读正文14px以上；不增加与阅读无关的动画。

审视：不套用通用仪表卡片。保留原高奢设计，以品牌资料和阅读节奏为重点；将用户要求的虚荣心相关内容呈现为辨识度、身份表达、圈层认同、稀缺感及个性表达，明确为编辑解读，不虚构消费效果或升值保证。

资料存入 profiles.editorial JSONB，包含 story/products/valueReading/socialSignals/considerations/references。后台创建、修订、预览与另一位审核员发布沿用现有权限和版本机制。新增资料可绑定既有上榜品牌，现有资料不可静默重新绑定品牌身份。真实品牌资料与虚构演示资料区分，真实资料需有公开HTTPS来源。原品牌信息无资料时不编造故事。

新增16个一级品类，保留原ID和后台改名/启停。品牌资料种子只新增缺失的明确条目，不覆盖后台编辑。资金与打榜规则保持现有实现。
