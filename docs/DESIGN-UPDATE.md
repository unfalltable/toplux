
# 本轮界面与规则更新
依据2026-10-27用户新要求，覆盖设计包旧版“无跨品类总榜”的约束；原始设计包保留作为历史参考。

产品名：奢榜；英文视觉标识 SHÈBANG。导航“全部品类”改为“奢品图鉴”。

首页只保留商家累计总榜，不设品类筛选。统一按同一商家所有品类的有效金额汇总，每个推广品牌只出现一次，同名不同账号不合并。排序：汇总净额降序、该商家所有条目最近变动时间升序、商家ID升序。原有分类商家榜独立保留，付款/退款仍归原品类，不改历史流水。

布局参照用户指定的toolcup.lol：第二、第一、第三名并排，冠军居中抬高；移动端冠军优先。第四名起用普通列表。移除旧表盘主视觉、探索品类、编辑推荐和底部宣传模块。页面首屏聚焦榜单，不加入虚构访客和点击。

视觉使用现有宋体标题和清晰无衬线正文。瓷白 #FAFAF9、墨黑 #1C1917、香槟金 #B99A5B、银灰 #BAC1C5、铜棕 #A97B55、边框 #E4E1DC。只在前三名使用奖台式层次，其余列表保持克制。保留明确商业推广披露和沙箱标记。

后台品类支持新增、改名、排序、启停；无物理删除，保留历史资金。品牌支持新建草稿、编辑修订、第二人复核、下线。修订待审核期间原公开版本继续展示，审批时检查版本，禁止自审和过期覆盖。
