# 本轮设计与数据方案

参考劳力士与劳斯莱斯官网的居中品牌识别、整幅影像、留白及精细排版。采用深松绿 #102B26、炭黑 #101916、铂金白 #F8F9F7、古铜金 #C5AC78、石灰 #69716D。中文标题使用系统宋体，英文与金额使用 Georgia，正文使用微软雅黑。摄影表现产品工艺，不冒用真实品牌背书。

布局：顶端居中奢榜字标 → 横向公众导航 → 左侧总榜宣言与右侧腕表摄影 → 三甲（第二 / 第一 / 第三）→ 其余名次。不增加首页推荐区。手机冠军先呈现，再显示二、三名。平台后台采用独立侧栏、管理导航和内容表格；商家数据使用自有品牌筛选、指标、趋势及渠道表。

数据：品牌在榜单可视区域持续一秒计曝光；打开品牌详情计浏览；经审核链接通过服务端跳转计点击。使用匿名第一方访客标识去重，不采集 IP。统计只表示本站发生的访问及引流，不等于站外直播观看或成交。商家仅查看自有推广品牌，管理员查看全站。支持7/30/90天筛选与CSV导出。新统计从接入后累计，无虚构历史数据。

旧 manage 路由兼容重定向商家数据；旧投入、订单功能移至独立推广账单，不再使用商家中心名称。
