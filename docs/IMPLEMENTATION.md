
# 当前实现与设计差异
本次由空目录开始开发，不初始化项目 Git，也未推送或部署。
设计原件保留在 design/。这是首版本地开发实现，不是完整生产交付。

- API：NestJS 容器 + Express 路由，PostgreSQL SQL 迁移；默认 PGlite 本地持久引擎，配置 DATABASE_URL 后使用 pg 连接外部 PostgreSQL。
- 演示入口：React + TypeScript + Vite，同时承担运营后台和额外的浏览器消费者演示。
- Flutter：Riverpod + go_router + Dio，提供发现、24类目录、搜索、资料详情、同类对比、累计榜、外链确认；账号同步与商家管理尚未迁移到 Flutter。
- 资金：沙箱订单、服务端收款、唯一收据、不可变流水、余额、成功退款在事务中完成。无真实渠道回调；不能宣称已完成真实验签或对账。
- 无 Redis/BullMQ 业务消费者、S3、Prisma、正式短信登录、品牌榜版本/回退/快照分页、发票、账号注销/数据导出、全平台深链验证。
- 演示有24类，每类3个虚构品牌档案；没有编造真实口碑。当前全部显示资料目录/榜单待完善。
- 正式支付、原生购买入口均关闭。APP_ENV=production 禁用开发登录和沙箱，但正式账号认证尚未实现，不能上线经营。
- 当前 API 使用精简实现契约，未完全符合原始 OpenAPI。见 docs/API.md，不能直接用原始 OpenAPI 生成客户端并假定所有端点可用。

## 首页及后台当前实现
产品名奢榜，导航奢品图鉴。按用户2026-10-27新要求，首页展示全站商家累计总榜，不提供品类筛选。品牌跨品类有效金额汇总一次，按净额、最近变动时间、商家ID排序。前三名为奖台布局，后续列表展示；旧版底部推荐模块移除。分类商家榜继续保留。

运营后台支持品类增改、排序与启停；品牌新建、修订、第二人审核与下线。修订在独立表中待审，发布前保留旧版并检查版本冲突。当前账号计划任务可常驻启动本地API，正式认证仍未接入。

## 本轮平台后台、商家数据及网页视觉
- Web取消“商家中心”入口，使用独立平台后台 /#admin、自有品牌数据 /#analytics、推广与账单 /#promotion。平台ADMIN看到全站访问，商家只能查看自有推广品牌。
- 数据由analytics_events持久保存，001/002迁移后自动应用003；不回填虚构流量。支持可视1秒的榜单曝光、详情PV/UV、审核外链服务端302点击、7/30/90天趋势和CSV导出。
- 官网类型允许公开HTTPS域名；店铺/直播/视频仍使用既有平台域名白名单。新增链接审核通过后才可展示和跳转。
- Web重做顶部字标与导航、工艺影像首页、三甲、图鉴、品牌卡和独立后台布局。图片保存本地，不依赖运行时外部图片服务。图片来源见docs/IMAGE-SOURCES.md。
- 本轮仅重做Web；Flutter保持先前界面，尚未同步新视觉与看板。新统计以Web为准。
- 当前统计有事件键去重与基础频率限制，未接入生产级机器人识别或站外平台归因。正式支付与认证仍待接入。
