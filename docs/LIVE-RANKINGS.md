# 首页统一榜单与到账动效

日期：2026-10-27。

## 页面与视觉

首页默认全品类总榜；删除独立“品类榜”导航，保留“奢品图鉴”。榜单标题旁的独立下拉筛选切换指定品类，图鉴的品类浏览仍只负责品牌资料。旧 #board 地址回到默认首页。

沿用深松绿、象牙白与古铜金、宋体标题及 Georgia 金额。三甲仍为第二/冠军/第三，手机冠军在前。浮动感由品牌标识轻移与阴影深浅表达，按钮位置保持稳定。名次变化时按同一品牌身份进行 950ms 位移动画，支持普通行进入三甲、三甲跌出及三甲之间交换；金额用 750ms 数字过渡，显示升降和新晋提示。没有额外推荐区。

## 数据与到账反馈

前台每 3 秒拉取榜单；后台标签页不轮询，重新可见后立即更新，超时 10 秒后恢复自动重试。请求可取消，切换品类不接收旧响应，失败时保留最近成功数据并提供重试。

005 迁移新增 ranking_heads、ranking_payments 及用于事务串行化的单行锁。成功收款事务在入账后保存唯一到账事件，订单号唯一约束和原收款幂等共同避免重放。未支付、失败和回滚不产生特效。

同一品牌 30 秒内连续成功到账，按品牌跨品类累积连击；第二次显示连击，第三次及以后显示“暴击助力”。此为视觉反馈，不翻倍金额或修改排名规则。提示不公开付款访客身份，不自动播放声音。本人确认付款后从回执立即取得同一到账事件，无需等待轮询；页面其他访客经 3 秒更新收到。动画队列最多保留 8 条，最近事件最多返回 20 条，首次进入以当前游标开始，不回放历史。

总榜及每个品类独立保存本次榜首开始时间；同一榜首追加金额不重置，榜首变化、下线后恢复重新开始。查询与资金/可见性写入使用同一事务锁；时长以服务器时间为基准。旧库从本功能首次启用开始记录，不捏造启用前的历史霸榜时间。

减少动态效果偏好下关闭浮动、位移、光环和数字过渡，保留静态金额、名次及到账提示。弹窗键盘约束沿用既有实现。

## 接口增量

GET /api/v1/merchant-board 与 /api/v1/categories/:id/merchant-board：

- items：现有已排序榜单。
- scope：global 或 category:UUID。
- leaderSince：当前榜首本次领跑开始时间；空榜为 null。
- trackingSince：该榜单启用记录时间。
- serverTime、updatedAt：服务器时间。
- refreshIntervalMs：3000。
- activityCursor：十进制字符串游标。
- events：提供 ?after=游标 后返回新增到账，字段 id/merchant_id/category_id/name/amount_fen/combo/paid_at；首次请求为空。无效游标拒绝。

付款确认返回 event 字段，与轮询 events 使用相同编号，由前台去重。

榜单响应 no-store。真实支付尚未接入；当前由沙箱确认成功后触发同一入账与动效链路。
