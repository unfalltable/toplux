# 产品需求规格

## 1. 定位与目标

一句话：看懂一个品牌在人群中的位置，找到符合自己身份表达的选择，再发现愿意公开展示投入的商家。

核心心理顺序：希望被认可 > 想显得有品味 > 不想花钱却没人看出来 > 害怕选错和被懂行的人否定。
“虚荣心”是内部产品洞察，公开使用“品牌地位、辨识度、圈层认可、风格、场合”等表达。
不把用户划分为穷人或富人，不用商品定义人的价值。

可用宣传语：
- 看懂品牌，再做选择。
- 同样的预算，不同的表达。
- 一个牌子，值得被谁看见？

首版目标：用户能在 3 分钟内理解一个大品类的主要品牌差异，完成 2–3 个品牌对比，并按需进入商家店铺或直播。

## 2. 品类规则

品类只有一层，实体没有 parentId。正式初始列表见 categories.json。
24 个大品类：手表、箱包、珠宝、服装、鞋、配饰、香水、美妆护肤、汽车、摩托车、自行车、游艇、酒、手机、电脑、耳机、音响、相机、电视、家电、家具、文具、运动装备、户外装备。

“蓝牙耳机、头戴式耳机、笔记本电脑、台式电脑”不建立子品类、不建立子榜、不作为商家另付费入口。
功能形态可写在商品描述里；风格、预算、场合可用于筛选，但不生成新的品类 ID。
后台新增同样粒度的大品类即可扩展全品类覆盖。

品牌与品类为多对多：同一品牌的电脑、手机、耳机定位独立。不能把一个品类的档次或评分自动复制给另一品类。
同一商品有一个主品类；电视归电视，不重复作为家电榜商品。品牌可同时在电视和家电有真实的品牌资料，但不重复计算商品。

电脑、耳机等并非所有品牌都属于传统奢侈品。本平台关注其品牌溢价、消费形象和高端定位，不把“售价高”直接写成奢侈地位。

## 3. 人群、角色与权限

| 角色 | 主要行为 |
|---|---|
| 游客 | 浏览品类、品牌榜、品牌介绍、对比、商家榜、店铺或直播外链 |
| 注册用户 | 游客能力 + 跨端收藏、关注、消息、反馈、创建推广品牌 |
| 商家成员 | 管理所属商家资料、链接、直播状态、查看榜位与账单；OWNER 可付款和管理成员 |
| 内容编辑 | 编辑资料、依据与榜单草稿，不能自己完成最终发布 |
| 审核员 | 审核品牌、商家和链接，发布版本，处理反馈 |
| 财务 | 对账、审核退款，不能直接改榜位和累计金额 |
| 管理员 | 权限与配置；敏感动作审计，不能删除资金流水“改排名” |

浏览和跳转不强制登录。登录只发生在需要账号的动作上，并在完成后回到原位置。
商家榜中的“品牌名”是商家自填的推广展示名，不自动关联品牌库、不自动代表品牌官方。主体与官方授权核验均为可选增强功能，不是打榜必填项。

## 4. 品牌内容与排行

每个品类默认一个“品牌地位榜”，由编辑审核发布，排名有明确理由和版本。
次级排序“辨识度、圈层认可”在已有资料充分时提供；首版不凭空生成多套精确分数。

品牌卡片：
- 名称、官方拼写、发源地、品牌图片或文字标识。
- 当前品类的定位层级、排名、20–40 字定位说明。
- “大众辨识 / 圈层认可 / 身份表达 / 风格辨识”标签。
- 已审核、待补充或演示标记，更新时间与依据入口。
- 收藏、对比操作。

品牌详情的固定结构：
1. 一句话理解：面向哪些消费语境，擅长表达什么。
2. 市场定位：主要商品、价格带、可比品牌；价格必须有地区、币种、时间、新品或二手口径。
3. 为什么有人愿意买：辨识度、风格、象征意义、品牌故事、自我奖励、收藏等。
4. 谁更容易认可：大众、爱好者、特定场合；只表述有证据的样本与编辑判断。
5. 常见赞誉与争议：每条独立来源；不能用少数帖子代称“全网都认为”。
6. 代表系列：最多 3–6 个，避免首屏变商品货架。
7. 适合与需要考虑：场合、显眼程度、搭配、持有成本；工艺参数作为支撑而非唯一主轴。
8. 同预算对比、相近品牌。
9. 商家与直播：单独模块，带“商业推广”。
10. 引用、修订记录、纠错。

定位层级默认五档：殿堂级、奢华级、高端级、精品级、进阶级；允许该品类配置不适用。
它是平台编辑框架，不是官方认证或用户身份评级，不同品类档位不直接等值。
标签采用“较高 / 中等 / 较低 / 资料不足”，不伪造样本量和 98.7 之类精度。

品牌榜排序由版本化的 editorial_rank 决定。发布时要求：
- 该品类至少 5 个品牌资料；不足则展示资料目录和“榜单待完善”。
- 每个上榜项有结论、理由、来源和复核人。
- 每版同一品牌只出现一次，名次连续且唯一。
- 商家支付不参与品牌榜排序。商家本身的资金榜另行展示。

## 5. 消费端 P0 功能

| 编号 | 功能 | 完成条件 |
|---|---|---|
| C01 | 一层品类目录 | 24 类可进入，同一套分类用于品牌榜、商家榜和入驻 |
| C02 | 品牌搜索 | 中文名、英文名、别名、拼音命中；分类内和全站搜索明确 |
| C03 | 品牌榜和详情 | 最新已发布版本、依据、更新时间、缺失资料状态 |
| C04 | 品牌对比 | 同品类最多 3 个，比较地位、辨识、场合、价带与争议 |
| C05 | 收藏与关注 | 登录后跨端同步；游客对比可本地临时保存 |
| C06 | 商家累计榜 | 按所选大品类累计有效打榜额排名，公开金额 |
| C07 | 商家详情 | 品牌名、Logo、金额必有；介绍、店铺、视频、直播等仅在选填后展示 |
| C08 | 外部跳转 | 用户主动点击，展示目标平台，有可用的失败处理 |
| C09 | 分享 | 分享品类、品牌、对比和商家链接；海报标注来源和日期 |
| C10 | 纠错与举报 | 理由、提交反馈、后台处理状态，不强迫公开个人资料 |

首版“直播”是外部直播入口，不包含主播端、推流、弹幕、礼物、实时推荐算法或自营直播交易。
外部介绍视频优先跳转；有合法托管素材时可在站内播放短介绍，默认不自动播放。

## 6. 商家端 P0 功能

核心路径：进入某大品类商家榜 → 我要打榜 → 填品牌名、上传 Logo、输入金额 → 登录或恢复账号 → 确认付款 → 累计金额和榜位更新。
当前品类由上下文带入；支付与服务条款用系统确认，不要求额外经营资料。

必填仅三项：
1. 品牌名：2–40 个字符，公开展示。
2. 展示 Logo：上传图片，审核可用。
3. 本次打榜金额：人民币整数元，符合最低金额与限额。

其他均选填：品牌介绍、店铺链接、直播间链接、介绍视频、联系方式、城市、关联品牌库、主体资料、授权凭证。
缺少任何选填项，不得阻止建档、支付、上榜或后续追加；不展示“资料未完善所以不能打榜”的流程。

- 名称和 Logo 做基础内容审核，不默认索取营业执照、地址、联系人或官网。争议处理是独立流程。
- 一个账号可拥有多个推广品牌；一个推广品牌在同一大品类只有一个累计条目。品牌可参加多个大品类，但资金分开。
- 同名不自动合并不同账号的资金。账户内重复品牌名提示复用已有档案；他人同名及冒用争议进入审核。
- 未付费档案在用户自己的管理页可见，金额为零不占榜位。
- 无店铺、直播、视频或介绍时，公开条目只展示品牌名、Logo、累计金额、名次及规则；点击可看金额说明，不制造空详情页。
- 选填资料可在首次上榜后随时添加；链接审核不影响原有合规的基础条目展示。
- 前三名可突出展示，但不能遮挡“商业推广”和金额口径。
- 支付前展示所选品类、有效累计、本次金额、预计名次及退款政策；名次不锁定、不保证永久第一。
- 资金展示为累计实付、累计已退、有效打榜额；每一项可追溯。
- 直播、店铺等选填后提供访问统计；没填时不显示无意义的零数据面板。
- 自报直播状态有来源和有效期；没有第三方回传时不显示观看人数、成交量或 GMV。

## 7. 运营后台

导航：工作台 / 品类 / 品牌与系列 / 品牌榜版本 / 商家审核 / 链接审核 / 内容反馈 / 订单 / 退款与对账 / 展示配置 / 用户权限 / 审计。

必须支持草稿预览、双人复核、版本发布与回退、定时下线、理由记录。
回退内容不回退支付账本；隐藏推广品牌只改变展示资格，不抹去财务记录。
大品类删除改为停用。存在品牌、商家或资金记录时不能物理删除。

## 8. 数据与内容生产

内容字段拆为 factual、editorial、community 三种：
- factual：官网、可靠档案、公开价格等事实与引用。
- editorial：平台编辑判断，带适用市场、理由和复核人。
- community：真实收集的用户反馈，带样本范围；样本不足就不展示统计。

AI 可辅助提取、翻译、写初稿和找缺失字段；未经来源核对与人工审核不能自动发布品牌地位结论。
不要伪造论坛评价、访客数、榜单购买、店铺、支付成功或直播状态。
图片记录来源和使用权；没有可用资产时显示文字标识。演示素材与真实素材隔离。

正式首发内容目标：24 类均有至少 5 个审核品牌品类档案、一份有效品牌榜。
内容丰富度是运营交付，不要求开发 AI 编造 120 份真实口碑。
开发演示种子每类至少 3 个明确标注“演示”的资料项，用于页面全覆盖；未满足 5 个的榜单按规则显示待完善。

## 9. 收入和增长

主收入：品类累计榜上的真实推广投入。首版不叠加入驻年费、付费认证和会员墙，降低理解成本。
后续：有披露的商业专题、专业咨询、获得合法回传后的导流合作。不得用付费购买品牌档次。

用户增长入口：品牌对比分享、品类档位卡片、场合选择内容、用户收藏。
商家增长入口：免费建档、真实访问数据、公开投入与名次、可分享的商家荣誉卡。
荣誉卡写“某品类商家推广榜第 X，截至某时，有效打榜额 ¥X”；不能写成官方质量评奖。

要验证：内容是否促成对比与收藏；公开金额是否增加点击；商家点击质量和追加投入是否成立。
不把付费额等同自然人气或经营资产。对外可称“商家热度榜”，首屏同时解释“按累计有效打榜投入排序”。

## 10. 优先级

P0：上述完整浏览、内容后台、累计资金闭环、商家链接与直播导流、基础数据统计。
P1：真实用户口碑分布、品牌关注更新通知、商家成员细权限、更多官方跳转 SDK、主题内容。
P2：已验证需求后的个性化推荐、用户搭配展示、更多语言与地区语境。
月榜、子品类榜不在任何计划中；只有用户后续明确改变要求才引入。
